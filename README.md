# Teman Bumil — Panduan Makan & Gizi Interaktif

Aplikasi web interaktif panduan nutrisi dan menu makanan harian/mingguan untuk ibu hamil yang dirancang khusus ramah untuk keluarga di Indonesia.

🌐 **Live Demo (GitHub Pages):**  
👉 [https://randyfauzi.github.io/panduangiziistrirandy/](https://randyfauzi.github.io/panduangiziistrirandy/)

---

## 🌟 Fitur Utama

1. **Menu Hari Ini**: Jadwal sarapan, makan siang, makan malam, dan camilan sehat dengan fitur rotasi/tukar menu (*swap*).
2. **Menu Mingguan (7 Hari)**: Rencana menu lengkap selama satu minggu yang seimbang dan bergizi.
3. **Panduan Makanan Aman & Dihindari**: Filter kategori makanan yang dianjurkan, dibatasi, atau wajib dihindari selama masa kehamilan demi keselamatan janin.
4. **Vitamin & Nutrisi Penting**: Informasi kebutuhan harian asam folat, zat besi, kalsium, DHA, dan vitamin esensial lainnya.
5. **Daftar Belanja Interaktif**: Checklist belanja bahan segar mingguan dengan pengelompokan sayur, protein, buah, dan kebutuhan dapur.
6. **Kontrol Usia Kehamilan**: Navigasi minggu kehamilan (dimulai dari minggu ke-7) dengan rekomendasi nutrisi sesuai trimester.
7. **Cetak Menu (Print Friendly)**: Siap cetak langsung untuk ditempel di kulkas atau dibawa belanja.

## 🚀 Cara Menjalankan

### Akses Online
Buka tautan [GitHub Pages](https://randyfauzi.github.io/panduangiziistrirandy/) di browser HP, tablet, maupun komputer.

### Akses Lokal (Offline)
Cukup buka file `index.html` atau `panduan_gizi_ibu_hamil_interaktif.html` di web browser apa pun tanpa perlu install dependency tambahan.

## ⚙️ Pengaturan GitHub Pages

Project ini sudah dilengkapi otomatis dengan GitHub Actions Workflow (`.github/workflows/pages.yml`).

Jika ingin memastikan Pages aktif melalui pengaturan repository:
1. Buka repo di GitHub: **Settings** > **Pages**.
2. Pada bagian **Build and deployment** > **Source**:
   - Pilih **GitHub Actions** (otomatis menggunakan workflow `pages.yml`), **ATAU**
   - Pilih **Deploy from a branch** > branch `main` / root (`/`).
3. Website akan langsung aktif di `https://randyfauzi.github.io/panduangiziistrirandy/`.
